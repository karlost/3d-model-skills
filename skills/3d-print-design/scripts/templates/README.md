# Project templates

`p1s_project_settings.config` is the `Metadata/project_settings.config` of a project saved in Bambu Studio 2.08: Bambu Lab P1S 0.4 nozzle, 0.20mm Standard, Textured PEI Plate, one filament, system presets only.

Its values come from Bambu Studio's presets, so this file is under **AGPL-3.0** like [Bambu Studio](https://github.com/bambulab/BambuStudio). The rest of the repository is MIT.

Another printer: create a project in Bambu Studio with one filament and system presets only, save it as `.3mf` and pass it as `write_3mf(..., template="my_printer.3mf")`.
